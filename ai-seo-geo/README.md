# AI SEO / GEO Learning Sprint

This lab turns AI SEO, AEO, GEO, and technical search concepts into practical TypeScript exercises and portfolio evidence.

## Outcomes

By the end of the sprint, you should be able to:

- Explain crawl, index, rank, retrieval, citation, and recommendation.
- Model search intent and entities in TypeScript.
- Validate metadata and structured data.
- Build small technical SEO audit utilities.
- Represent GEO/AEO visibility observations as typed evidence.
- Produce a portfolio-ready case study from completed exercises.

## 7-Day Path

1. `day-01-search-foundations/` — crawl, index, rank, intent, entities
2. `day-02-technical-seo/` — status codes, canonicals, robots, sitemap, indexability
3. `day-03-structured-data/` — schema.org and JSON-LD validation
4. `day-04-aeo-geo/` — answer-engine and generative-search evidence models
5. `day-05-content-architecture/` — topic/entity graphs and internal linking
6. `day-06-portfolio/` — audit evidence and case-study packaging
7. `day-07-income/` — job-ready skills map and interview exercises

## Working Rule

Do not copy answers first. Attempt each exercise, run it, explain what happened, then compare against the reference guidance.
